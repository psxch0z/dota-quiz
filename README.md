# Викторина торговца — Dota 2

Мини-игра в духе старой "Trader's Quiz" из Dota 2: показывается собранный предмет,
нужно кликами выбрать из сетки его составляющие (с учётом количества, если компонент
повторяется — например Eye of Skadi = 2x Ultimate Orb + Orb of Frost).

Два режима: "Бесконечный" (9 компонентов на выбор — как было в игре) и "Бесконечный
(Hard)" (полный список всех предметов с поиском, без подсказок и ограничений на клики).
Вход через Steam и лидерборд по каждому режиму.

Играть можно прямо сейчас: **https://dota-quiz-4fea.onrender.com/**
(бесплатный тариф Render — если сайт "спал", первая загрузка может занять ~30-50 сек).

## Стек

- Фронтенд: HTML/CSS/JS без сборки (`public/`).
- Backend: Flask (`server/app.py`) — раздаёт фронтенд, ведёт игровой раунд на сервере,
  вход через Steam OpenID, API лидерборда.
- База: PostgreSQL (например, бесплатный [Neon](https://neon.tech)) через `psycopg`
  (`server/db.py`). Строка подключения — в `DATABASE_URL`.
- Данные о предметах — сгенерированный JSON (`public/data/items.json`) из открытого
  датасета OpenDota (`odota/dotaconstants`). Иконки — с Steam CDN.
- Деплой: Render (веб-сервис из этого репозитория, автодеплой при пуше в `main`) +
  Neon (Postgres).

## Установка

```
pip install -r requirements.txt
```

Скопировать `.env.example` в `.env` и заполнить:
- `STEAM_API_KEY` — получить на https://steamcommunity.com/dev/apikey (в поле
  "Domain Name" для локальной разработки можно указать что угодно, например `localhost`).
- `SITE_URL` — адрес, на котором крутится сайт (для локалки — оставить как есть,
  для деплоя — заменить на реальный публичный адрес; от него зависит, куда Steam
  вернёт пользователя после входа).
- `FLASK_SECRET_KEY` — любая случайная строка, например:
  `python -c "import secrets; print(secrets.token_hex(32))"`
- `DATABASE_URL` — строка подключения к Postgres (Neon и подобные сервисы обычно
  выдают её сразу в нужном виде: `postgresql://user:password@host/dbname?sslmode=require`).
  Таблицы (`users`, `scores`) создаются автоматически при первом запуске.

## Запуск

```
python server/app.py
```

и открыть http://localhost:8420/

Один процесс отдаёт и фронтенд, и API — не нужен отдельный статический сервер и
не будет проблем с CORS/cookie между разными портами.

## Деплой

Продакшен-запуск — через gunicorn:

```
gunicorn --chdir server app:app
```

Текущий деплой: Render (Build command — `pip install -r requirements.txt`, Start
command — команда выше) + Neon для базы. Free-тир Render засыпает после 15 минут
без запросов и просыпается по первому обращению; Neon хранит данные постоянно и
не теряет их при простое.

## Обновить данные о предметах

Если Valve выпустит патч с новыми предметами, повторить:

```
curl -sL "https://raw.githubusercontent.com/odota/dotaconstants/master/build/items.json" -o items_raw.json
python scripts/build_data.py
```

Скрипт `scripts/build_data.py` отбирает предметы с рецептом из 2+ компонентов и
собирает `public/data/items.json` с двумя списками:
- `recipes` — предметы-цели викторины (иконка, название, цена, состав, включая
  альтернативные варианты рецепта через `answers`, если у предмета их несколько,
  как у Power Treads);
- `pool` — все предметы, которые встречаются как компоненты (сетка для выбора).

## Известные ограничения

- Данные о предметах (`items.json`) полностью доступны клиенту, поэтому кто-то
  технически подкованный теоретически может открыть консоль браузера и подсмотреть
  правильный состав рецепта заранее. Сам факт зачисления очков при этом подделать
  нельзя — см. ниже.

## Защита от читерства

Раунд ведёт сервер, а не браузер:

- `POST /api/round/start` / `POST /api/round/next` — сервер сам выбирает следующий
  рецепт и хранит его ключ вместе со счётом в подписанной cookie-сессии
  (`server/app.py`, `FLASK_SECRET_KEY`). Без секретного ключа сервера её нельзя
  подделать так, чтобы подпись осталась валидной.
- `POST /api/round/answer` — клиент присылает только выбранные компоненты, а не
  готовый счёт. Правильность проверяется на сервере по собственной копии
  `items.json` (`server/quiz_data.py`), и только сервер увеличивает счёт и пишет
  рекорд в лидерборд.
- Повторно ответить на один и тот же вопрос нельзя (нужно сначала запросить
  следующий), плюс минимальный интервал между ответами — это защищает от скрипта,
  который бы дул правильные ответы в цикле быстрее, чем реально можно играть.

## Идеи для дальнейшего развития

- Режимы: на время, "hard mode" без названия предмета, только по иконке.
- Фильтр по типу предмета (кто-то может хотеть тренироваться только на артефактах).
